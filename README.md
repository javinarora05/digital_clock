# ⏰ Digital Clock

> A lightweight neon-style digital clock built with HTML, CSS and vanilla JavaScript.

## ✨ Features
- Live time updated every second
- Dark/neon visual style
- Minimal responsive layout
- No frameworks or dependencies

## 🧠 How it works
JavaScript reads the current `Date`, formats the time, updates the DOM and repeats with `setInterval()`.
